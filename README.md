# LeetCode Solutions - Advanced Algorithms

This repository contains my personal solutions to various competitive programming and algorithmic problems from LeetCode, implemented in Python. 

The focus of these solutions is efficiency, clean code, and the application of advanced data structures.

## 🛠️ Tech Stack & Concepts Covered
* **Language:** Python 3
* **Algorithms & Techniques:** 
  * Breadth-First Search (BFS) & Depth-First Search (DFS)
  * Dynamic Programming (DP) & Memoization
  * Backtracking & Bitmasking
  * Graph Theory (Shortest Paths)
  * Trie Data Structures

## 📁 Repository Structure
Each folder is named after the LeetCode problem ID and title. Inside, you will find the optimized solution script explaining the core logic in its filename.

* `0010-regular-expression-matching` - Dynamic Programming / Memoization
* `126_de_LeetCode_Word_Ladder_II` - Bidirectional BFS + DFS Cache
* `212_Word_Search_II` - Trie + DFS with Pruning
* `787_Cheapest_Flights_Within_K_Stops` - Graph Algorithms (Dijkstra/Bellman-Ford variant)
* *(And more...)*
